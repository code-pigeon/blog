| 类别 | 渠道名称 | 数据领域/内容 | 备注说明 |
|---|---|---|---|
| 中国全国数据 | 国务院官网 | 宏观经济数据、部委相关数据 | 可视化好，下载方便，按部委整合了数据获取链接 |
| 中国全国数据 | 国家统计局 | 国家层面月度、季度、年度宏观数据 | 地区数据和全球数据指标不多 |
| 中国地方数据 | 地方统计局导航（国家统计局整合） | 各省市统计数据 | 可分类查看并下载，如上海市统计局 |
| 中国地方数据 | 省份/城市 + 数据开放（如上海公共数据开放平台） | 地方政府各部门官方统计数据、部分政府认证的第三方数据 | 数据比统计局更多更全 |
| 行业数据 | 行业协会（如中国钢铁工业协会、中国汽车工业协会） | 钢铁、汽车等行业数据 | 免费、简单方便，如钢企、钢产量、价格、汽车产销、进出口等 |
| 行业数据 | 第三方数据服务平台/研究平台 | 各行业专门数据 | 文中未展开，每个行业可单独做视频 |
| 其他国家数据 | 其他国家统计局导航（国家统计局官网） | 各国官方统计数据 | 直接链接到各国官方统计部门或数据分析网站 |
| 其他国家数据 | Open Data Inception | 世界各国宏观数据库整合 | 收录各国/地区数据库数量，如日本气象厅、国土地理院、统计局 |
| 全球数据 | 国际组织导航（国家统计局官网） | 全球维度数据 | 列出常见国际组织网站链接 |
| 全球数据 | 世界银行等国际组织网站 | 全球数据 | 找 data 或 statistic 图标进入数据库，免费下载 |
| 数据整合平台 | 知网 | 年鉴数据：全国、地方、各行各业 | 需学校图书馆账号或各省市图书馆账号，支持检索和下载 |
| 数据整合平台 | 萝卜投研 | 行业研究报告、宏观数据、国内/世界/行业数据 | 方便白嫖，无需转发充值，可直接下载 Excel |
| 其他特色数据 | 七麦数据 | App 热度数据 | 可查看不同国家 iOS 和安卓系统 App 热度、实时榜单 |
| 其他特色数据 | 产大师 | App 热度数据 | 与七麦数据类似 |
| 其他特色数据 | App Annie | App 热度数据 | 与七麦数据类似 |
| 其他特色数据 | 房天下 | 地产数据、房价指数 | 住宅、土地交易、地产商销售数据；中国100个主要城市房价变动 |
| 其他特色数据 | 高德地图指数 | 交通实时数据 | 全国主要城市交通实时状况排行，火车站、机场、收费站、高速、景区拥堵排行 |
| 其他特色数据 | 亿恩 | 电影、电视剧、综艺数据 | 票房、上座率、排片情况等 |
| 其他特色数据 | 猫眼专业版 | 电影、电视剧、综艺数据 | 与亿恩类似，App 体验比网页端更好 |
